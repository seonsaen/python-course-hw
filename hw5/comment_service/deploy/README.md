# Comment Service Инструкция

## Как применять миграции

### Если проект запущен в Docker:
Выполните команду для запуска миграций внутри контейнера бэкенда:
`docker compose exec backend python manage.py migrate`

### Если проект запущен через Makefile:
Убедитесь, что база данных работает, и выполните:
`make migrate`

## Как создать новые миграции
При изменении моделей данных выполните:
`make migrations`
